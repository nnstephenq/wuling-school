# 雾岭小学（暂名）

恐怖 + 悬疑的情景解谜网页游戏。用 HTML + CSS + JavaScript 做成，**不用安装任何软件**。

> 二十年前，雾岭村寄宿小学的一场大火之后，你八岁的弟弟失踪了。二十年后，你收到一个包裹，里面有一张字条：“他不在山上。”

目前版本：**v0.1**（完整流程能玩到底，图片是临时版）。

## ▶ 在线试玩

**https://nnstephenq.github.io/wuling-school/**

点开就能玩。建议用电脑玩；用手机玩的话请横过来，并打开右上角的“显示可调查”。

## 怎么玩

在线试玩，或者下载后双击 `index.html`，用 Chrome 或 Edge 打开。全程用鼠标。

| 操作 | 说明 |
|---|---|
| 点画面里的东西 | 调查。鼠标移上去会显示名字 |
| 左下角的人名 | 和人说话、**出示物品**给对方看 |
| 右下角的按钮 | 去同一个地方的其他房间 |
| 笔记本 | 已知的事、当前的疑问。想通了的时候，这里会出现“推理” |
| 物品 | 看拿到的东西和文件 |
| 地图 | 去村子里的其他地方 |
| 显示可调查 | 卡住时用，会把能点的地方都框出来 |

进度会**自动保存**，下次打开选“继续游戏”。

## 内容

- 序章 + 4 章，13 个场景
- 3 次推理问答、1 个密码锁、2 次“给某人看证据”
- 最后在祠堂用 8 条证据证明 4 件事
- 4 个结局：沉默、带他回家、真相、回声（隐藏）

## 文件夹结构

```
wuling-school/
├── index.html              网页入口
├── css/style.css           网页外观
├── 剧本设计.md              完整剧本、时间线、漏洞自检
├── 画图清单.md              每张图的构图和提示词
├── 图片检查结果.md          临时图哪些要重画
├── 新图片/                  原图（豆包生成，带水印；只留在本机，不上传）
├── assets/                 ← 内容：改剧情主要改这里
│   ├── config/config.js      全局设定
│   ├── images/               处理好的图（scenes / characters / items）
│   └── story/
│       ├── scenes.js           场景、可以点的地方、对话（最主要的文件）
│       ├── items.js            物品和文件的内容
│       ├── characters.js       人物名字和立绘
│       ├── notebook.js         笔记本里的句子
│       ├── places.js           地图上的地点
│       ├── deductions.js       推理问答
│       └── endings.js          结案和结局
└── src/                    ← 代码
    ├── main.js               入口：进场景、执行剧情、结局
    ├── core/                 进度存档、条件判断、检查剧情文件有没有写错
    ├── systems/actions.js    执行剧情的每一句
    └── ui/                   画面：场景、对话框、笔记本、地图、推理、密码锁、结案……
```

## 架构设计

1. **内容和代码分开**：所有文字、对话、物品、地点、推理都在 `assets/story`，代码只负责读取。
2. **剧情用“一句一句”的列表写**：例如 `"一句心里话"`、`{ chen_yi: "陈姨说的话" }`、`{ give: "journal" }`。`scenes.js` 开头有完整说明。
3. **一个文件只做一件事**：例如 `mapView.js` 只管地图，`puzzleView.js` 只管密码锁。
4. **依赖只往下走**：`main.js` → `systems` → `ui` → `core`。
5. **写错会有中文提示**：物品名字打错、场景不存在，网页一打开就会告诉你错在哪里。
6. **图片缺了不会坏**：找不到的图会自动隐藏，游戏照样能玩。

## 怎么改（不用懂代码）

所有文件都可以用记事本打开（保存时编码选 **UTF-8**），改完按 **F5** 刷新。

| 想做的事 | 改哪里 |
|---|---|
| 改对话、旁白 | `assets/story/scenes.js` |
| 改文件内容（周记、报告、日记……） | `assets/story/items.js` 的 `doc.text` |
| 改密码锁的答案 | `scenes.js` 搜索 `puzzle` |
| 改推理问题和选项 | `assets/story/deductions.js` |
| 改结局文字 | `assets/story/endings.js` |
| 换图片 | 用同样的文件名覆盖 `assets/images/` 里的图 |
| 换图后对齐点击位置 | `config.js` 把 `showHotspots` 改成 `true`，看虚线框，再改 `scenes.js` 里的 `rect` |
| 打字速度 | `config.js` 的 `typeSpeed` |

> 为什么 assets 里用 `.js` 而不是 `.json`？双击打开网页时，浏览器不允许读取 `.json` 文件；`.js` 可以正常载入，所以不需要任何服务器。
